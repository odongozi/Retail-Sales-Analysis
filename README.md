# Retail Sales Analysis

## Project Overview
This project uses Python, PostgreSQL, and Power BI to analyse retail sales data, evaluate profitability, and identify sales performance trends to support data-driven business decisions.

## Objectives
- Analyse revenue, profit, and sales volume.
- Identify the best-performing sales channels and regions.
- Evaluate product and sales team performance.
- Develop actionable business recommendations.

## Tools and Technologies
- **Python:** Data cleaning, analysis, and visualisation using Pandas and Matplotlib.
- **PostgreSQL:** SQL queries and business analysis.
- **Power BI:** Interactive dashboard development.

## Business Questions
1. Which sales channel generates the highest revenue?
2. Which sales team has the highest profit margin?
3. Which product has the highest profit margin?
4. Which region has the highest number of orders?
5. Which product category has the highest average selling price?

## Methodology
1. Data inspection and cleaning.
2. Exploratory data analysis using Python.
3. Business analysis using PostgreSQL.
4. Dashboard development using Power BI.
5. Interpretation of findings and recommendations.

## Project Structure
- `data/` — Dataset files.
- `python/` — Python notebooks.
- `sql/` — SQL queries.
- `sql-visualizations/` — SQL charts and visualisations.
- `power-bi/` — Power BI report.
- `images/` — Dashboard screenshots.
- `documentation/` — Project documentation.

## Key Findings
Key findings will be documented using the actual results from the Python analysis, SQL queries, and Power BI dashboard.

## Recommendations
Recommendations will be based on the verified findings to help improve sales performance, profitability, and business decision-making.

## Limitations
The analysis is limited to the information and time period available in the dataset. The findings describe observed sales patterns and do not necessarily establish causation.
